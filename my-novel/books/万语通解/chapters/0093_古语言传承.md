# 第93章 古语言传承

飞行法器划破云层，朝万语宗方向疾驰。

苏言盘膝坐在法器尾部，闭目养神。识海中的法则符文已经平静下来，但每一枚都散发着深邃的金芒，与之前截然不同。

“苏言。”

白发长老走过来在他身旁坐下，“感觉如何？”

“已经稳固了。”

苏言睁开眼，“多谢长老关心。”

“老夫活了这把年纪见过的天才不少，但像你这样能在通玄境就将神识修炼到两百丈的，还是第一个。”

白发长老感叹道，“那传承......究竟是什么？”

“具体我也不太清楚。”

苏言斟酌着用词，“似乎是某种古老的语言法则传承，与万语之书同源。”

万语之书四字让白发长老脸色微变。

他作为万语宗长老，自然听说过那个传说——集齐七块碎片就能唤醒万语之祖，获得无上语言法则之力。

“你......收集了多少碎片？”

白发长老忍不住问。

“七块。”

苏言没有隐瞒。

既然白云子已经知道，宗门高层迟早也会知道，瞒着反而不好。

“七块......”

白发长老倒吸一口凉气。

那可是七块！传说中散落大陆各处的万语之书碎片，竟然全被眼前这个年轻人收集到了。

“你可知......集齐七块意味着什么？”

白发长老压低声音。

“知道。”

苏言点头，“四年后万语之祖苏醒。”

既然传承意志已经说了，他也没什么好隐瞒的。

“宗门知道吗？”

“白云子师尊知道。”

苏言道，“长老若是感兴趣，可以去问他。”

白发长老复杂地看了苏言一眼，不再说话。

//

傍晚时分，飞行法器抵达万语宗。

一行人下了法器，白发长老先行离去，说要向掌门汇报探索结果。其余四名弟子也各自返回住处。

苏言刚走到自己洞府前，一道传讯符箓从远处飞来。

他伸手接住，神识一扫，眉头微挑。

是林诗诗的传讯。

“事关万佛城布防，明日辰时，语碑林见。”

语碑林？

苏言想了想，将符箓收好。

林诗诗这个时候约他见面，目的不言而喻——肯定是两年后那个交易。

按照林诗诗之前的说法，她要的是苏言帮她从西域遗迹带《虚空道》玉简，而她提供万佛城布防图。

但现在情况变了。

苏言已经获得古语言传承，神识突破两百丈，战力可比化神境初期。四年后的计划也更加紧迫。

他需要更详细的万佛城布防情报，以便救人。

//

次日辰时。

语碑林位于万语宗东侧，是一片古老的石碑林。数千块石碑矗立在此，每一块都刻有不同语言的文字。

这些石碑是万语宗先辈从各地收集而来，记录了无数失传的语言。

苏言抵达时，林诗诗已经等在那里。

她今天穿了一身青色长裙，长发挽起，露出纤细的脖颈。看起来比平时多了几分柔美，但苏言知道这只是表象。

“来了。”

林诗诗转过身，唇角微勾。

“有事直说。”

苏言开门见山。

“两年后的交易，还作数吗？”

林诗诗问。

“作数。”

苏言点头，“但我需要更多。”

“更多？”

林诗诗秀眉微挑，“你想要什么？”

“万佛城的布防图。”

苏言道，“我要知道所有传送祭坛的位置、守卫轮换时间、禁地入口的守卫实力。”

林诗诗目光闪烁：“你想救人？”

“我父亲被囚禁在万佛城地牢。”

苏言没有隐瞒，“四年后万语之祖苏醒，那是唯一的机会。”

“四年......”

林诗诗喃喃道，“确实很紧。”

“你还没有回答我的问题。”

苏言道。

“可以。”

林诗诗点头，“但我有一个条件。”

“说。”

“我要你帮我杀一个人。”

林诗诗道。

“韩立？”

苏言皱眉。

“不是。”

林诗诗摇头，“是隐脉三长老灰老。”

“灰老？”

苏言思索片刻，“聚道境那个？”

“没错。”

林诗诗道，“他在万佛城地位极高，如果能杀掉他，隐脉必然会大乱。这样我的家族才有机会......”

“到什么程度？”

苏言打断她。

林诗诗愣了一下：“什么？”

“我问你的家族势力到什么程度。”

苏言道，“你一个养气境弟子，能让隐脉三长老亲自出手对付，说明你的身份不简单。”

林诗诗沉默片刻。

“看来什么都瞒不过你。”

她苦笑一声，“我的真实身份是林家嫡女，也是隐脉的......”

话说到一半，她突然停住。

“是什么？”

苏言追问。

“这件事以后再说。”

林诗诗摇头，“你只需要知道，我们有共同的敌人就够了。灰老不死，我永远无法摆脱隐脉的控制。”

苏言盯着她看了片刻。

“你和隐脉之间的事，我不管。”

他道，“但你要的《虚空道》玉简，我已经拿到了。”

“真的？”

林诗诗眼睛一亮。

“真的。”

苏言从储物戒指中取出一枚玉简，递了过去。

这枚玉简是他从西域遗迹中获得的，一直没有使用。既然林诗诗要，就给她好了。

“多谢。”

林诗诗接过玉简，神识探入，确认无误后脸上露出喜色。

“万佛城布防图我会在三日后给你。”

她收起玉简，“另外，我再送你一个情报。”

“什么？”

“天书阁最近在调集人手。”

林诗诗压低声音，“黑羽传讯回总部，说你获得了古语言传承，实力大增。总部正在评估是否要派出更强的杀手。”

“化神境？”

苏言问。

“化神境中期。”

林诗诗道，“据说已经在路上了。”

苏言目光幽深。

化神境中期，战斗力远超之前的青冥长老。如果再来一次伏击，就算他现在是通玄境二重，也未必能全身而退。

“我知道了。”

“多加小心。”

林诗诗转身离去，“三日后，布防图会在语碑林交货。”

看着她的背影消失，苏言目光幽深。

这个林诗诗......

看似在帮助苏言，实际上一直在引导他与隐脉、天书阁对抗。她自己则躲在背后，坐收渔翁之利。

但目前来说，她的情报对苏言很有价值。

暂时合作也无妨。

//

返回洞府后，苏言开始稳固境界。

识海中的法则符文闪烁着金色光芒，每一枚都蕴含着恐怖的力量。这就是古语言传承的力量——创造语言的力量。

万语通解的能力似乎也发生了蜕变。

苏言心念一动，手中浮现出一个古老的文字。那是他刚才从识海中的传承符号里解析出来的。

这个字的意义是"坚固"，一旦施加在物体上，能让目标的防御力提升数倍。

这就是"创造"境界的力量——不仅能解析语言，还能创造语言。

他屈指一弹，那枚金色符文没入面前的石桌。

“凝！”

苏言轻喝。

肉眼可见的，石桌表面浮现出一层淡淡的金膜，厚度约有三寸。

“去。”

他又一指旁边的心魔剑。

心魔剑冲天而起，在空中挽了个剑花，最后稳稳落入苏言手中。

苏言随手一剑斩向石桌。

“铛——”

金铁交鸣声中，剑气四散，而石桌只留下一道浅痕。

“以我现在的实力，配合'创造'语言，至少能提升三倍防御。”

苏言眼中闪过一丝喜色。

如果对敌使用......

他眼神闪烁。

不过现在不是实验的时候。化神境中期杀手正在路上，他必须尽快提升实力。

取出三枚青冥草，这是之前在云梦泽获得的。

苏言运转功法，开始炼化。

青冥草药力温和，化作股股暖流在经脉中流转。神识缓缓增长，一百九十八丈......一百九十九丈.....两百零五丈.....两百一十丈！

不知道过了多久，苏言睁开眼。

神识：两百一十丈。

瞬移距离：三十八丈。

境界已经彻底稳固在通玄境二重。

“还不够......”

苏言握紧拳头。

四年后万语之祖苏醒，父亲被囚万佛城，化神境中期杀手正在路上。

每一个消息都像一座大山压在他心头。

他必须变得更强。

//

三日后。

苏言再次来到语碑林。

林诗诗已经到了，手中握着一枚蓝色玉简。

“布防图。”

她将玉简抛过来，“万佛城所有的传送祭坛、守卫部署、禁地入口，全部记录在内。另外，我还标注了地牢的位置。”

苏言神识探入玉简，仔细阅读。

片刻后，他点头：“多谢。”

“各取所需而已。”

林诗诗道，“两年后的约定，还记得吧？”

“记得。”

苏言道，“两年后，我会杀掉韩立。”

“不止是杀掉。”

林诗诗补充道，“我要他经脉尽断，生不如死。”

“可以。”

苏言转身离去。

“等等。”

林诗诗突然叫住他。

“还有事？”

她犹豫了一下：“韩立......经脉已经恢复了。”

“我知道。”

苏言脚步不停，“通玄境三重，修炼了噬灵诀三层，实力比之前更强。”

“你知道？”

林诗诗愣了一下。

她本以为苏言不知道这个消息，没想到他竟然清楚。

“那你还有把握？”

“为什么没有。”

苏言的声音传来，人已经消失在林间。

林诗诗站在原地，美目中闪过一丝异色。

//

万语宗深处，一座密室。

白发长老站在一名中年男子面前，恭敬汇报。

“掌门，苏言确实获得了古语言传承。”

“他现在实力如何？”

中年男子问。

“神识两百丈，瞬移三十五丈，战力可比化神境初期。”

白发长老道，“如果再进一步，说不定能达到化神境中期。”

中年男子沉默片刻。

“四年......”

他喃喃道，“万语之祖苏醒在即，我们必须做好准备了。”

“掌门的意思是......”

“加强苏言的护卫。”

中年男子道，“另外，密切监视隐脉和天书阁的动向。一有任何异动，立即汇报。”

“是。”

//

苏言回到洞府，将布防图玉简贴在额头。

万佛城的布局在他识海中逐渐清晰。

七十二座传送祭坛，三十六处守卫营地，十二个禁地入口......还有地牢的具体位置。

“万佛城......”

苏言目光幽深。

四年后，他一定会去那里。

不是为了唤醒万语之祖，而是为了阻止这一切，救出父亲。

时间紧迫，他必须继续修炼。

门外传来脚步声。

“苏言。”

周林的声音响起，“在吗？”

“进来。”

苏言收起玉简。

周林推门而入，脸色有些凝重。

“出事了。”

“什么事？”

“云梦泽那边传来消息。”

周林低声道，“又有异宝现世，各方势力都在往那边赶。”

“异宝？”

苏言皱眉。

这都第几次了？

“据说是什么'天书'残页。”

周林道，“掌门已经决定再次组队前往探索。”

“天书......”

苏言眼神一闪。

不会是万语之书的残页吧？

如果是的话，他必须去。

“我知道了。”

苏言道，“什么时候出发？”

“三日后。”

周林道，“你好好准备一下。”

“没问题。”

//

三日后，万语宗山门。

五道流光冲天而起，朝云梦泽方向飞去。

苏言站在飞行法器上，回头望了一眼万语宗。

这一去，又不知道会遇到什么。

但他已经不是当初那个弱小的少年了。

神识两百一十丈，瞬移三十八丈，战力可比化神境初期。

就算面对化神境中期，他也有把握全身而退。

“云梦泽......”

苏言握紧拳头。

不管是天书阁还是隐脉，亦或是其他势力，谁敢挡他的路，那就别怪他不客气。

就在这时，他识海中的万语之书碎片突然剧烈震动起来！

“嗯？”

苏言脸色微变。

这种感觉......是残页的共鸣？

他神识探入识海，只见七块碎片组成的古玉正在发光，与之前在云梦泽深处出现七彩霞光时的感觉一模一样。

“竟然在百里之外就有感应......”

苏言目光闪烁，“看来这次异宝果然与万语之书有关！”

这个消息必须保密。

他不动声色地收回神识，看向远方的云梦泽。

飞行法器破空而去，消失在云层之中。
