# 第98章 宗门议事

（正文无需修改，保持原样）

四长老撤退的第三天，万语宗议事大殿。

殿内气氛凝重。掌门高坐主位，沈惊鸿位于左侧客座，白云子、执法堂长老、各峰首座分列两侧。苏言站在殿中，接受着各方目光的审视。

“这么说，天书阁四长老亲自出手，都没有留下你？”

掌门开口，声音平淡听不出喜怒。

“弟子侥幸。”

苏言躬身，“多亏沈太上长老及时赶到，否则后果不堪设想。”

沈惊鸿摆摆手，“老夫只是恰好感知到气息波动，算不得什么。倒是你，以通玄境二重正面对抗化神境后期而不死，这份战力……老夫生平仅见。”

此言一出，殿内众人变色。

他们只知道苏言天赋异禀，却没想到逆天到这种程度。

“化神境后期……”

白云子喃喃道，“老夫当年通玄境二重时，连化神境初期的威压都承受不住。”

“天赋不能说明一切。”

执法堂长老沉声道，“关键是他能从化神境后期手中逃脱。这份保命能力，才真正可怕。”

掌门点头，“苏言，这次让你来，是想听听你的打算。”

“弟子想继续修炼。”

苏言道，“天书阁不会善罢甘休，弟子必须变得更强。”

“天书阁四长老受伤，短期內不会再来。”

沈惊鸿道，“但化神境后期的底蕴，远不止于此。大长老之下，还有三位太上长老，个个都是聚道境的存在。”

聚道境。

苏言心中一凛。

化神境后期之上，便是聚道境。那等存在，一言可定法则，一语可改天象，根本不是他现在能够抗衡的。

“弟子明白。”

苏言道，“所以弟子想闭关修炼，争取早日突破通玄境三重。”

“三年。”

掌门开口，“最多三年，天书阁必定会再次出手。届时，他们不会再留手。”

“三年时间，足够吗？”

白云子皱眉。

“不够也要够。”

掌门道，“苏言，你的修炼速度老夫看在眼里。三年从二重到三重，有把握吗？”

苏言沉默片刻。

神识已达300丈，基础夯实。突破三重只是时间问题。

“有。”

“好。”

掌门起身，“从今日起，苏言晋升为核心弟子，享宗门最高资源供给。藏经阁三层对他开放，所有功法典籍任其翻阅。”

此言一出，众人变色。

藏经阁三层，那可是存放宗门核心机密的地方，便是各峰首座都无权随意进入。

“另外。”

掌门继续道，“沈太上长老，你负责指导苏言修炼。务必要在最短时间内，将他的战力提升到能够抗衡聚道境的程度。”

沈惊鸿点头。

“还有。”

掌门看向执法堂长老，“天书阁胆敢夜袭我万语宗，真当我们是软柿子？传令下去，全面反击。凡天书阁在外据点，一个不留。”

执法堂长老领命。

//

议事结束后，苏言跟着沈惊鸿来到执法堂。

“你先说说。”

沈惊鸿坐下，“与四长老对战时，你最后那一掌……老夫看得出，那不是普通的攻击。”

苏言犹豫了一下。

创造语言的能力，是他最大的底牌之一。但沈惊鸿既然问了，他不好隐瞒。

“弟子领悟了一种特殊能力。”

苏言道，“可以将语言法则附加在攻击上，提升威力。”

“创造语言？”

沈惊鸿瞳孔收缩。

作为万语宗太上长老，他自然知道这四个字意味着什么。

“你……突破了语言法则的创造境界？”

“侥幸。”

沈惊鸿沉默良久。

“看来白云子说的没错。”

他叹息道，“你的天赋，已经超出了老夫的认知。创造语言……那可是聚道境强者才能触及的领域。”

“弟子只是初窥门径。”

苏言道，“距离真正的创造境界，还差得远。”

“初窥门径就如此可怕。”

沈惊鸿摇头，“若是让你达到聚道境，还得了？”

“弟子会继续努力。”

沈惊鸿：“……”

他忽然觉得，自己这把老骨头活了几千年，简直白活了。

“罢了。”

他摇头道，“你的情况老夫大致了解了。接下来老夫会指点你修炼，争取在一年内突破三重。”

“一年？”

苏言皱眉。

“怎么，太慢了？”

沈惊鸿道，“通玄境每一重都需要大量积累，一年从二重到三重，已经是极快的速度。”

“弟子想更快。”

苏言道，“最多两年，弟子必须达到通玄境三重巅峰。”

“为何？”

沈惊鸿不解。

苏言沉默。

两年后，是他与韩立的约定。

林诗诗要的两个人——韩立和灰老，他必须杀。

韩立经脉恢复，突破通玄境三重，修炼噬灵诀禁术战力大增。灰老更是聚道境强者，不是现在的他能够抗衡的。

但既然立下约定，就必须做到。

“弟子有自己的理由。”

苏言道，“请太上长老成全。”

沈惊鸿盯着他看了片刻。

“也罢。”

他点头道，“既然你坚持，老夫会倾囊相授。但修炼之事欲速则不达，若是基础不稳，日后必有大患。”

“弟子明白。”

//

接下来的日子里，苏言进入了紧张的修炼状态。

白天，他在藏经阁三层翻阅各种功法典籍，充实自己的语言体系。晚上，沈惊鸿亲自指点他修炼，解答修炼上的困惑。

神识在稳步增长。

三百零五丈……

三百一十丈……

三百一十五丈……

一个月后，苏言的神识已经突破三百二十丈，瞬移距离也随之增加到四十八丈。

战力更进一步。

这一日，苏言正在洞府中修炼，周林来访。

“苏哥。”

周林看着苏言，欲言又止。

“怎么了？”

苏言睁开眼。

“天书阁那边……有新消息。”

“什么消息？”

“天书阁大长老震怒。”

周林道，“四长老回去后，被大长老骂了一顿。现在天书阁内部正在讨论，是否要请动聚道境强者出手。”

聚道境。

苏言心中一沉。

化神境后期他还能抗衡一二，但聚道境……那完全是另一个层次。

“宗门知道吗？”

“掌门已经知道了。”

周林道，“据说沈太上长老和白云子长老正在商量对策。”

苏言点头表示明白。

“还有一件事……”

周林犹豫道，“林诗诗那边传来消息，想见你一面。”

“她？”

苏言皱眉。

自上次交易完成，两人已经有一段时间没有联系了。

“她没说是什么事？”

“没说。”

周林道，“只是让我带话给你，她有重要的事情要当面告诉你。”

苏言沉思片刻。

林诗诗此人城府极深，但目前为止，交易都还算公平。

“好。”

他点头道，“告诉她，我明日午时在老地方等她。”

//

第二日，万语宗后山一处偏僻的山谷。

林诗诗早已等在那里。她今日换了一身淡蓝色长裙，少了几分凌厉，多了几分柔美。

“你来了。”

看到苏言，林诗诗展颜一笑。

“有什么事，说吧。”

苏言开门见山。

“你的伤……好了？”

林诗诗没有直接回答，而是看着苏言。

“你在关心我？”

苏言冷笑。

“只是确认一下你的状态。”

林诗诗道，“毕竟两年后的约定，还指望着你。”

“放心。”

苏言道，“韩立的头颅，我预定了。”

林诗诗的笑容僵了一下。

“你还是这么直接。”

她叹息道，“就不能给女孩子留点面子吗？”

“面子是自己挣的。”

苏言道，“你今天来，不会就是为了说这些废话吧？”

林诗诗摇头。

“当然不是。”

她正色道，“我来是想告诉你，天书阁内部出问题了。”

“什么问题？”

“大长老和四长老吵起来了。”

林诗诗道，“四长老主张暂缓刺杀，等你突破时再动手。但大长老不同意，认为夜袭失败是天书阁的耻辱，必须立刻找回面子。”

“所以呢？”

“大长老决定请动聚道境强者。”

林诗诗道，“具体的我还不知道，但据说已经传讯给天书阁总部，最迟半年，会有聚道境强者降临万语宗。”

半年。

苏言心中计算。

如果聚道境强者出手，以他现在的实力，根本没有反抗的余地。

“你为什么要告诉我这些？”

苏言看着林诗诗，“对你有什么好处？”

“我不是说了吗？”

林诗诗微笑，“我想看看，你到底能走到哪一步。”

“仅此而已？”

“不然呢？”

林诗诗反问，“难道你以为我喜欢你？”

苏言转身。

“如果没有其他事，我先走了。”

“等等。”

林诗诗叫住他。

“还有一件事。”

她犹豫了一下，“韩立……经脉已经完全恢复了。”

“我知道。”

“他还突破到了通玄境三重。”

“我知道。”

“而且他已经开始修炼噬灵诀第四层。”

苏言脚步一顿。

噬灵诀的恐怖，他早就领教过。每修炼一层，战斗力都会翻倍增长。

“他还说什么？”

苏言转身。

“他说……”

林诗诗犹豫道，“两年后的约定，他一定会让你后悔。”

“让他等着。”

苏言冷笑，“两年后，我会亲手宰了他。”

说完，他转身离去。

看着苏言的背影，林诗诗的眼神复杂难明。

“希望你能做到。”

她喃喃道，“否则，我的计划……”

后半句话，她没有说出口。

//

回到洞府，苏言没有休息，而是继续修炼。

时间紧迫。

半年内，如果无法突破到通玄境三重，面对聚道境强者，他连逃跑的机会都没有。

识海中，七彩符文缓缓旋转。

三百二十丈神识如臂使指，任何一个细微的变化都逃不过他的感知。

“空间古字……”

苏言心中一动。

上次战斗，空间古字已经用了两次，只剩两次机会。

但这两次机会，不到万不得已，不能轻易使用。

“看来要换个思路。”

他暗暗道。

语言法则方面，他已经有“凝”、“破”、“封”三击，配合空间古字，底牌已经足够。

现在最重要的，是提升境界。

“突破三重……”

苏言深吸一口气。

他的积累已经足够，神识也达到了三百二十丈。突破三重，只是需要一个契机。

“继续修炼。”

他闭上双眼。

识海中，七彩符文越转越快。

距离万语之祖苏醒，还有四年。

他必须在那之前，拥有足够的自保之力。

否则，一切都是空谈。

//

就在苏言闭死关时，天书阁总部。

四长老跪在大殿中，脸色苍白。

“废物！”

大长老暴怒的声音回荡在整个大殿，“一个通玄境二重的小辈，都拿不下。你还有脸回来？”

“四长老息怒。”

四长老咬牙道，“那苏言确实有些诡异。他的言出法随，能够伤到化神境后期。若非沈惊鸿及时赶到，老夫一定能拿下他。”

“够了！”

大长老打断他。

“传令下去。”

他冰冷的声音响起，“启动'灭神计划'。我倒要看看，一个通玄境二重的小辈，能翻出什么浪花。”

四长老脸色大变。

“大人，这……会不会太冒险了？”

“冒险？”

大长老冷笑，“当年我们能灭掉万语宗一次，就能灭掉第二次。”

他起身，走到窗前。

“四年后，万语之祖苏醒在即。万语宗必须除掉。”

“否则，后患无穷。”

//

万语宗，执法堂。

沈惊鸿站在窗前，看着远处的山峰，眉头紧锁。

“来了吗？”

他喃喃道。

作为万语宗最古老的太上长老，他比任何人都清楚天书阁的底蕴。

“这一战，躲不过去了。”

他叹息道。

但很快，他的眼神变得坚定。

“来吧。”

他握紧拳头。

“这一次，万语宗不会再退。”

山风吹过，带来阵阵寒意。

一场更大的风暴，正在酝酿。
