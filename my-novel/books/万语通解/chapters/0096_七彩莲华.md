# 第96章 七彩莲华

云梦泽深处的水面上，七彩霞光流转，将整片湖面映照得如梦如幻。

那株七彩莲不过三尺高，通体由七种颜色的光芒交织而成。花瓣层层叠叠，每一层都散发着不同的气息，赤如火、金如阳、青如海、紫如渊……饶是苏言见多识广，此刻也不由得屏住呼吸。

“好一座奇珍。”

赵德全喃喃道，眼中满是震撼，“传说七彩莲千年一现，能洗涤神识杂质，提升神识强度。老夫修炼至今三百余年，也只在典籍中见过此物描述。”

四周万语宗弟子们同样一脸惊叹。便是苏言，目光也被七彩莲牢牢吸引。

但他的注意力，很快转移到那枚残缺石碑上。

石碑只有成年人拳头大小，半埋在湖底的淤泥中。若非方才七彩莲的光芒照见极易便会错过。石碑表面布满岁月的痕迹，但那几个古朴文字却清晰可见——

“空间”。

又是空间。

苏言心中一动。

他已经从"空间"古字中获得了三次使用机会，全部用罄。但这石碑上的“空间”二字，似乎与他之前获得的有所不同。

“苏言。”

赵德全的声音在旁边响起，“这七彩莲……宗门志在必得。你有什么想法？”

“弟子想试试能否收取。”

苏言直言。

赵德全点点头：“理应如此。你神识强大，此物与你最有缘法。”

他没有说的是，刚才苏言三招击败化神境中期的战力，已经彻底征服了在场的万语宗弟子。这等人物，日后成就不可限量。

苏言缓步上前。

七彩莲近在咫尺，浓郁的香气扑面而来。他的识海微微震颤，竟是自主运转起来。

“收敛心神。”

他暗暗提醒自己。

七彩莲能洗涤神识不假，但若强行收取，神识会被其内蕴含的法则之力冲击，轻则重伤，重则识海崩裂。

苏言运转万语通解，一缕神识探出，缓缓缠绕向七彩莲的茎秆。

“咦？”

他轻咦一声。

七彩莲并未排斥他的神识，反而传来一种亲近之意。就仿佛两者同根同源，本就是一体。

“难道是……”

苏言心中闪过一个念头。

他的神识已经达到225丈，识海中蕴含的空间符文虽然使用次数用罄，但本质已经改变。若七彩莲认可的是这种改变……

想到此处，他不再犹豫。

神识全面爆发，如潮水般涌向七彩莲。

“嗡——”

七彩莲剧烈震颤，七色光芒暴涨。四周弟子纷纷变色，下意识后退。

赵德全抬手布下一道结界，防止气息泄露。

“苏言！”

有人惊呼。

只见七彩莲在苏言神识的包裹下，竟然缓缓脱离水面，一寸一寸向他飞来。

苏言面色凝重。

他能感觉到七彩莲中蕴含的庞大能量，正在被识海吸收。那种感觉……就像干涸的土地迎来甘泉，贪婪地吞噬着一切。

识海中的法则符文开始震颤。

最先复苏的是那枚“坚固”符文，金光大盛；紧接着是“空间”符文，虽然使用次数用罄，但此刻竟然也亮了起来；再之后是其他法则符文，一枚接一枚，仿佛沉睡的巨兽逐一苏醒。

苏言的嘴角溢出一丝鲜血。

“不好！”

赵德全变色，“他承受不住了！快帮他！”

“长老不可！”

旁边弟子急道，“七彩莲认主期间，外人介入会让他神识崩裂！”

赵德全拳头紧握，却不敢妄动。

场内，苏言已经陷入奇异状态。

识海中，七彩莲的能量不断冲刷着他的神识。225丈的神识范围开始扩张——

230丈！

240丈！

250丈！

“这……”

苏言又惊又喜。

七彩莲的能量比他想象的更加精纯。神识提升的速度已经不能用“修炼”来形容，简直就是坐火箭。

260丈！

270丈！

280丈！

终于，当神识突破300丈大关时，七彩莲的能量方才耗尽。那株莲花彻底融入他的识海，化作一枚七彩符文，静静悬浮。

苏言睁开眼。

三百丈神识！

这已经是化神境后期的门槛！

“多谢长老护法。”

他起身向赵德全行礼。

赵德全已经完全愣住了。

“三……三百丈？”

他，结巴了。

作为通玄境巅峰的强者，赵德全的神识也不过年过百丈。苏言一个通玄境二重，神识比他高出三倍？

“侥幸突破。”

苏言淡淡道。

赵德全：“……”

他忽然想起掌门曾说过的话——此子日后成就，不可限量。

现在看来，还是保守了。

“那石碑呢？”

赵德全转移话题。

苏言看向湖底那枚残缺石碑。经过七彩莲的震荡，石碑又往上冒了一截，露出更多文字。

他跳入湖中，将石碑捞起。

“空间……”

石碑上只有这两个字，但笔画间蕴含的法则气息，却让他心神震荡。

这并非普通文字，而是一种更古老的“空间”表达方式。

与他之前获得的“空间”古字相比，这枚石碑上的“空间”二字更加原始，更加接近空间法则的本源。

“创造语言……”

苏言心中闪过一个念头。

万语通解已经达到“创造”境界，不仅能解析现有语言，更能创造新语言。而这石碑上的“空间”二字，恰是他创造新符文的绝佳材料。

他没有声张，只将石碑收入储物戒指。

“长老。”

苏言看向赵德全，“弟子想在此地闭关一日，稳固境界。”

“应该的。”

赵德全自然不会反对。

万语宗弟子们开始撤离。异宝已经认主，此地不宜久留。天书阁虽然退去，但难保不会去而复返。

苏言盘膝坐下，识海中的七彩符文缓缓旋转。

神识：225丈→300丈（五彩莲提升75丈）
瞬移：40丈→45丈（空间法则共鸣）

战力评估：可比化神境后期！

“化神境中期杀手……”

苏言心中冷笑。

现在再来，他有把握在五招内解决。

//

一日后。

苏言稳固境界，起身离开湖面。

“多谢长老。”

他向赵德全道谢。

“客气。”

赵德全道，“你的实力增长速度，委实惊人。看来用不了多久，老夫就不是你的对手了。”

“长老说笑了。”

苏言摇头。

赵德全深深的看了他一眼：“天书阁二长老伏击失败，必然不会善罢甘休。那名化神境中期虽然被你所伤，但天书阁底蕴深厚，随时可能派出更强的杀手。你……小心些。”

“弟子明白。”

苏言点头。

他早就有心理准备。天书阁与他的仇怨已经不死不休，不是杀掉几个杀手就能解决的。

除非……彻底覆灭天书阁。

这个念头刚冒出来，就被苏言压下。

还不到时候。

他的修为虽然进步神速，但与真正的顶尖势力相比，还是太弱了。天书阁有聚道境底蕴，不是现在的他能抗衡的。

“先回宗门。”

苏言道。

//

万语宗。

苏言返回洞府，将那枚残缺石碑取出。

“空间……”

他运转万语通解，神识探入石碑。

这一次，石碑中的法则气息不再抗拒，而是主动与他融合。

识海中，那枚已经用罄的“空间”符文微微震颤，竟然开始吸收石碑中的能量。

“还能补充？”

苏言又惊又喜。

空间古字使用三次后彻底耗尽，他还心疼了许久。却没想到，这石碑竟然能补充！

一枚，两枚，三枚……

石碑中的能量不断涌入识海，“空间”符文的光芒越来越亮。

当石碑彻底暗淡下去时，苏言识海中的“空间”符文，已经恢复到可以使用两次的程度！

“两次……”

苏言眼中精光闪烁。

加上其他底牌，他的战力已经今非昔比。

化神境中期？不足为惧。

便是化神境后期，也可一战！

//

就在苏言闭关巩固修为时，天书阁内部却炸开了锅。

“你说什么？二长老伏击失败？！”

天书阁大长老拍案而起。

下方，黑羽单膝跪地，头颅低垂。

“大长老息怒。属下没想到那苏言战力如此之强，三招便击败了一名化神境中期。二长老当机立断，选择撤退……”

“撤退？”

大长老冷笑，“天书阁创立至今，何时有过撤退的先例？”

黑羽不敢接话。

“二长老呢？”

大长老问。

“二长老……正在养伤。”

黑羽犹豫了一下，“那苏言的言出法随，对化神境中期都有奇效。二长老虽然境界更高，但也不愿冒险……”

“废物！”

大长老怒骂。

黑羽头垂得更低了。

“传令下去。”

大长老道，“让三长老……不，四长老出手。”

“四长老？”

黑羽变色，“大长老，四长老可是化神境后期！他亲自出手，是否太看得起那苏言了？”

“怎么，你有意见？”

大长老目光如刀。

“属下不敢。”

黑羽连忙道。

“四长老一旦出手，苏言必死无疑。”

大长老冷冷道，“但此人还有些价值。记住，我要活的。”

“是！”

黑羽退下。

大长老站在窗前，望着远处的天空。

“古语言传承……”

他喃喃道，“老夫志在必得。”

//

万语宗。

苏言并不知道天书阁的动向。

此时的他，正站在宗门任务堂，接取新的任务。

“西域遗迹探索……”

他看着任务列表。

宗门最近在组织西域遗迹的深入探索，奖励丰厚。但苏言已经有了空间石碑和七彩莲，对一般的遗迹已经没有兴趣。

“苏言！”

身后传来熟悉的声音。

苏言回头，看到周林正向这边走来。

“你出关了？”

周林上下打量他，“境界稳固了？”

“差不多了。”

苏言点头。

“我听说云梦泽那边……”

周林压低声音，“七彩莲被你得了？”

“消息传得这么快？”

苏言挑眉。

“废话。”

周林翻了个白眼，“你现在可是宗门红人。三招击败化神境中期，这等战绩，足以震动整个宗门了。”

“我还有事，先走了。”

苏言不想太过招摇。

“等等。”

周林拉住他，“林诗诗让我带话给你。”

“说。”

苏言脚步一顿。

“她说……天书阁又派杀手了。”

周林低声道，“这次是化神境后期，比之前所有的都强。你……小心些。”

化神境后期？

苏言眼神微冷。

来的还真快。

“知道了。”

他淡淡道。

周林犹豫了一下：“苏言，你……有什么打算？”

“兵来将挡，水来土掩。”

苏言道，“该来的总会来，躲也躲不掉。”

他向任务堂外走去。

“周林。”

走了几步，他忽然停下。

“怎么了？”

周林问。

“最近不要出宗门。”

苏言道，“天书阁既然派出化神境后期，杀手锏必然不少。你修为尚浅，若是遇到……”

他没有说完，但周林明白他的意思。

“放心。”

周林重重点头，“我会的。”

//

离开任务堂，苏言直径前往藏经阁。

既然天书阁派出化神境后期，他的修炼必须更加刻苦。

“藏经阁顶层……”

他想起掌门的承诺。

藏经阁顶层收藏的都是万语宗核心功法，价值连城。悟道崖能加速法则领悟。禁地灵泉能洗涤经脉杂质。

“先去藏经阁顶层看看。”

苏言做出决定。

藏经阁顶层只有核心弟子才有资格进入，平日里戒备森严。但苏言手持掌门令牌，一路畅通无阻。

“《天阙语》第三层……”

他找到一枚记载空间法则的玉简。

《天阙语》是他目前主修的空间功法，已经入门。但第三层的内容更加高深，涉及空间法则的本质。

“瞬移的距离可以进一步提升……”

苏言心中暗喜。

他现在的瞬移距离是45丈。如果能突破到第三层，达到百丈也未必不可能。

“百丈瞬移……”

他光是想想就激动。

化神境后期强者虽然强大，但面对百丈瞬移，也只能干瞪眼。

“修炼！”

苏言握紧拳头。

时间紧迫，他必须尽快提升实力。

四年后万语之祖苏醒，父亲还在万佛城地牢受苦。

他没有退路。

//

就在苏言闭死关时，万语宗外，却迎来了一批不速之客。

为首的是一名黑袍老者，面容苍老，但气息强大，赫然是化神境后期！

“四长老。”

黑羽跟在身后，“万语宗就在前面。”

“嗯。”

四长老点点头，目光看向万语宗深处。

“就是那个苏言？”

“不错。”

黑羽道，“此子虽然只是通玄境二重，但战力可比化神境中期巅峰。属下怀疑，他获得了古语言传承。”

“古语言传承……”

四长老眼中闪过一丝贪婪。

古语言传承的价值，不可估量。一旦获得，他的实力将更上一层楼。

“准备一下，今夜动手。”

四长老道。

“是！”

黑羽领命。

一场针对苏言的杀机，正在悄然酝酿。
