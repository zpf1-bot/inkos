# 第101章 荒原风云

万语宗，议事大殿。

晨钟刚刚敲响，大殿内已经聚集了十几位长老。为首的是掌门玄清真人，左右分别是沈惊鸿和白云子。殿中还站着几道气息强横的身影，都是万语宗的核心战力。

“人都到齐了。”

玄清真人环顾四周，“开始吧。”

执法堂长老上前一步，手里握着一份玉简。

“云梦泽遗迹崩塌后，各方势力都在收缩。但最近，西域传来消息。”

他法力注入玉简，光幕在殿中展开。

那是一幅地图，标注着西域的荒原部族领地。代表荒原部的红色区域，正在向万语宗的势力范围逼近。

“荒原部族？”

有长老皱眉，“他们不是在北域边境吗？”

“情况有变。”

执法堂长老道，“三个月前，荒原部族突然大举迁徙，穿过死亡沙漠，现在已经在距离万佛城三百里的地方扎营。”

“死亡沙漠？”

白云子脸色微变，“那可是连化神境都不敢轻易踏入的绝地。荒原部族是怎么过去的？”

“根据探子回报，他们掌握了一种特殊的语言能力。”

执法堂长老道，“可以让沙漠中的蜃兽为他们所用，形成天然的保护屏障。”

“蜃兽？”

沈惊鸿开口，“就是那些能制造幻境的沙漠怪物？”

“对。”

执法堂长老点头，“荒原部族历代供奉蜃兽神，但现在看来，他们已经控制了蜃兽群。”

大殿陷入沉默。

荒原部族是西域的古老势力，民风彪悍，全民皆兵。如果让他们在万佛城附近站稳脚跟，对万语宗来说绝对是巨大的威胁。

“掌门。”

这时，白云子开口，“老夫记得，荒原部族的核心语言是荒原语吧？”

“不错。”

玄清真人点头，“荒原语是草原部族的根本，和我们的语言体系有本质区别。”

“老夫有个提议。”

白云子道，“既然荒原部族掌握了我们不了解的力量，那我们也该有所准备。”

“你是说……”

玄清真人看向白云子。

“苏言。”

白云子道，“让他去探查荒原部族的虚实。”

大殿安静了一瞬。

苏言这个名字，如今在万语宗可以说是如雷贯耳。创造语言的能力，古语言传承的获得者，这些光环加在一起，让他成为宗门最受关注的核心弟子。

“苏言现在的实力……”

有长老犹豫道，“让他去荒原部族，会不会太冒险了？”

“正因为他的实力够强，才让他去。”

沈惊鸿开口，“换作别人，可能连荒原部族的面都见不到，就被杀了。”

“惊鸿说的有理。”

玄清真人点头，“苏言现在虽然只是通玄境二重，但战力已经不弱于化神境后期巅峰。有他出手，安全性反而更高。”

“那就这么定了。”

白云子道，“老夫这就去通知苏言。”

//

万语宗，内门洞府。

苏言刚刚结束修炼，识海中神识流转，三百三十丈的神识范围如潮水般扩散。这是他目前的极限，再想提升，需要更多的积累。

“荒原语……”

他喃喃道。

荒原语是草原部族的核心语言，和其他灵语有本质区别。根据宗门记载，荒原语是“以血为誓、以骨为铭”的语言，每一句话都需要消耗使用者的气血和寿命。

正因为如此，荒原语的威力远超普通语言。一名修炼荒原语的战士，可以凭借一句话就让敌人血流成河。

“荒原语入门需要气血……”

苏言皱眉。

他现在的气血虽然比同境界修士强一些，但距离修炼荒原语还有一段距离。

“看来得先提升气血。”

苏言心中盘算。

就在这时，洞府外的禁制被触动。

“苏言。”

是白云子的声音。

苏言起身，打开禁制。

白云子站在外面，手里拿着一份玉简。

“师尊？”

苏言有些意外。

“有人找。”

白云子道，“跟我来。”

//

穿过层层禁制，苏言跟着白云子来到一座偏僻的石屋。

石屋门口，站着两名灰袍人。

“就是他？”

其中一人上下打量苏言。

“在下苏言。”

苏言淡淡道，“两位是？”

“荒原部族使者。”

那灰袍人道，“我部大祭司有请。”

苏言心中一动。

荒原部族，竟然主动找上门来了。

“大祭司？”

苏言问道，“请我去做什么？”

“自然是好事。”

另一名灰袍人道，“苏公子获得了古语言传承，我部大祭司很感兴趣。”

苏言沉默片刻。

荒原部族在这个节骨眼上出现，显然不是巧合。再加上师尊白云子亲自带路，这里面的意味就值得深思了。

“好。”

苏言点头，“我跟你们去。”

//

荒原部族驻地在万语宗西北方向三百里的一处山谷。

说是山谷，其实是一片绿洲。在四周黄沙的包裹下，这片绿洲显得格外突兀。

苏言跟着两名灰袍人穿过沙漠，终于在天黑前抵达了绿洲。

“苏公子，请。”

灰袍人引着苏言进入绿洲中心的一座帐篷。

帐篷内点燃着篝火，火光映照着一张苍老的面孔。

那是一名老妇人，满头银发，脸上刻满了岁月的痕迹。她的眼睛很亮，像是能看穿一切。

“老身见过苏公子。”

老妇人站起身，“老身是荒原部族的大祭司，你可以叫我察哈尔。”

“察哈尔大祭司。”

苏言点头，“不知大祭司找我有什么事？”

“自然是为了荒原语。”

察哈尔大祭司笑道，“苏公子应该知道，荒原语和其他语言不同。”

“愿闻其详。”

苏言道。

“荒原语是以血为誓的语言。”

察哈尔大祭司道，“每一句荒原语，都需要消耗使用者的气血。所以修炼荒原语的人，必须有强健的体魄。”

“这一点我知道。”

苏言道。

“老身听说，苏公子获得了古语言传承，能够创造新的语言字符。”

察哈尔大祭司看着苏言，“不知道，苏公子能否创造荒原语？”

苏言心中一凛。

创造荒原语，这对他来说是一个全新的挑战。

“我可以试试。”

苏言道。

“好。”

察哈尔大祭司点头，“老身可以给你一个机会。”

她挥手，一名年轻的荒原战士走进帐篷，手里托着一个托盘。

托盘上，放着一块血红色的石头。

“这是荒原神石。”

察哈尔大祭司道，“里面蕴含着荒原语的法则碎片。只要你能解析它，就能掌握荒原语。”

苏言看着那块神石。

他能感觉到，神石中蕴含着一股古老而强大的气息。那种气息，和他之前接触的任何语言都不同。

“就这么简单？”

苏言问道。

“当然不是。”

察哈尔大祭司笑道，“荒原神石不是谁都能解析的。如果苏公子没有足够的实力，不仅无法解析神石，还会反噬自身。”

苏言沉默片刻。

他知道这是一个考验。但风险越大，收益越大。如果他能在荒原语上有所突破，对他的实力将是一次巨大的提升。

“好。”

苏言伸手握住神石。

//

神石入手，苏言立刻感觉到一股庞大的信息涌入识海。

那是一种完全不同于其他语言的信息流。荒原语的法则碎片像是一把把钥匙，每一把都对应着一种古老的力量。

“这就是荒原语的基础法则……”

苏言心中明悟。

他运转万语通解，开始解析这些法则碎片。

识海中，神识之力如潮水般涌动。每一枚法则碎片，都在被缓慢地分解、重组。

时间一分一秒地过去。

苏言的脸色开始变得苍白。荒原语的解析难度，远超他之前的任何一次。即便是金戈语和玄水语加起来，也没有荒原语这么复杂。

“不行……”

他咬紧牙关。

如果现在放弃，不仅无法解析荒原语，还会受到反噬。

“凝！”

苏言心中轻喝。

识海中，新创造的“凝”字符文骤然亮起。淡金色的光芒将识海照亮，一股奇异的力量从符文中涌出。

那是创造的力量。

在这股力量的作用下，荒原语的法则碎片开始重新组合。它们不再是碎片，而是形成了一个完整的体系。

“原来如此……”

苏言睁开眼，眼中闪过一丝明悟。

荒原语的本质，是“以血为誓、以骨为铭”。它的法则核心，是“牺牲”和“奉献”。

只有愿意为了族人奉献一切的人，才能真正掌握荒原语。

“这就是荒原语的法则雏形……”

苏言喃喃道。

他松开神石，感觉识海中多了一些东西。那是一枚全新的符文，虽然还很淡薄，但确实存在。

“多谢大祭司。”

苏言站起身，“我成功了。”

察哈尔大祭司看着苏言，眼中闪过一丝惊讶。

她原本只是想让苏言试试，没指望他真的能成功。毕竟荒原神石的解析难度她是知道的，即便是荒原部族的天才，也需要数月甚至数年的时间。

但苏言只用了不到一个时辰。

“苏公子果然名不虚传。”

察哈尔大祭司道，“从现在起，你就是荒原部族的朋友。”

//

离开荒原部族驻地，苏言立刻返回万语宗。

他的识海中，那枚新生的荒原语符文正在缓缓旋转。虽然还很淡薄，但已经成型。

“荒原语入门了……”

苏言心中喜悦。

荒原语的入门，意味着他的语言法则又向前迈进了一步。虽然只是雏形，但足以让他在面对荒原部族时拥有一定的话语权。

更重要的是，荒原语的“以血为誓”法则和他的“凝”字有异曲同工之妙。两者都是通过牺牲来获得力量，只是方向不同。

“如果我能把荒原语和‘凝’字结合起来……”

苏言心中闪过一个念头。

不过现在还不是时候。荒原语只是入门，想要达到能够运用自如的程度，还需要大量的时间。

“先回去禀报师尊。”

苏言加快速度。

//

万语宗，议事大殿。

苏言将荒原部族的情况如实汇报。

“你说什么？”

有长老惊呼，“荒原部族愿意和我们和平共处？”

“不错。”

苏言道，“大祭司承诺，只要我们不干涉荒原部族的迁徙，他们就不会侵犯万语宗的领地。”

大殿陷入议论。

这个消息太突然了。荒原部族大举迁徙，所有势力都以为他们要发起战争。但现在看来，事实并非如此。

“苏言。”

玄清真人开口，“你觉得荒原部族的目的是什么？”

“弟子猜测，他们是为了躲避什么。”

苏言道，“死亡沙漠虽然危险，但荒原部族有蜃兽保护，不应该突然迁徙。”

“你是说……”

“有更强大的敌人，在追赶他们。”

苏言道。

大殿安静了一瞬。

能让荒原部族如此狼狈的敌人，会是什么样的存在？

“先不要声张。”

玄清真人道，“暗中调查荒原部族迁徙的真正原因。”

“是。”

众人应道。

//

离开议事大殿，白云子叫住了苏言。

“苏言。”

白云子道，“你的荒原语，现在到什么程度了？”

“刚刚入门。”

苏言道，“只掌握了最基本的法则雏形。”

“足够了。”

白云子点头，“荒原语和其他语言不同，越往后越难。你能这么快入门，已经超出为师的预期。”

“多谢师尊。”

苏言道。

“为师这里有一份功法。”

白云子递给苏言一份玉简，“是荒原语的修炼心得。你拿回去好好参悟，争取早日突破到小成境界。”

苏言接过玉简，神识探入。

玉简中记录的，是荒原语的修炼方法和一些修炼心得。虽然只是基础，但对现在的他来说正好合适。

“多谢师尊。”

苏言再次道谢。

“还有一件事。”

白云子道，“天书阁那边有动静了。”

苏言心中一凛。

“根据探子回报，天书阁已经请动了一位聚道境强者。”

白云子道，“预计三个月后就会到来。”

“这么快？”

苏言脸色微变。

“他们的动作比想象中快。”

白云子道，“你只有三个月的时间了。”

苏言沉默。

三个月，从通玄境二重突破到化神境，这几乎是不可能的事。但他没有退路，只能拼尽全力。

“弟子明白。”

苏言道。

//

回到洞府，苏言开始修炼荒原语。

识海中，那枚淡薄的荒原语符文正在缓缓吸收周围的法则之力。每吸收一点，符文就变得更加凝实一分。

“以血为誓、以骨为铭……”

苏言心中默念荒原语的口诀。

他能感觉到，自己的气血在缓慢地消耗。虽然消耗不大，但如果持续下去，也会对他的身体造成负担。

“看来需要找一些补充气血的方法。”

苏言心中盘算。

宗门宝库中应该有类似的灵药，但贡献点……

他算了算自己的贡献点，只有170点，不够兑换什么好东西。

“先修炼着，等突破后再想办法。”

苏言收回思绪，继续沉浸在修炼中。

识海中，三百三十丈的神识如潮水般涌动。荒原语符文在神识的温养下，慢慢变得凝实。

距离突破，又近了一步。

//

三个月后。

万语宗，某处山谷。

这里是宗门专门为核心弟子设立的闭关场所，四周布满了禁制，寻常人无法进入。

苏言盘膝坐在山谷中央，周身气息澎湃。

三个月的不间断修炼，让他的荒原语终于突破到了小成境界。

识海中，荒原语符文已经不再淡薄，而是变成了一个完整的符文体系。这个体系和“凝”字不同，更加古老、更加神秘。

“这就是荒原语小成……”

苏言睁开眼，眼中闪过一丝精芒。

他能感觉到，自己的实力又提升了一个档次。虽然境界还是通玄境二重，但战力已经可以和化神境后期巅峰抗衡。

“如果现在再面对灰羽，应该能秒杀他。”

苏言心中评估。

灰羽是化神境巅峰，之前还能和他过上几招。但现在，荒原语小成之后，他的实力已经有了质的飞跃。

“苏言。”

一个声音从山谷外传来。

苏言起身，打开禁制。

周林站在外面，脸色有些凝重。

“出什么事了？”

苏言问道。

“天书阁的人来了。”

周林道，“宗门让你去议事大殿。”

苏言心中一凛。

终于来了。

//

万语宗，议事大殿。

气氛凝重到了极点。

苏言走进大殿，发现殿中已经站满了人。为首的是掌门玄清真人，左右分别是沈惊鸿和白云子。在他们对面，站着三道身影。

为首的是一名中年男子，身穿黑袍，面容冷峻。他的气息内敛，但隐约透露出强大的威压。

化神境巅峰强者。

苏言心中判断。

“苏言。”

玄清真人开口，“这位是天书阁的赤霄长老。”

“赤霄长老。”

苏言点头。

“这就是你们万语宗的天才？”

赤霄长老看着苏言，眼中闪过一丝惊讶。

显然，他也没想到苏言会这么年轻。

“苏言，还不快见过赤霄长老。”

有长老催促道。

“不必了。”

赤霄长老淡淡道，“本座今日来，是奉大长老之命，带苏言回去一趟。”

此言一出，大殿气氛顿时紧张起来。

“不可能。”

沈惊鸿开口，“苏言是我万语宗弟子，哪都不去。”

“怎么，你们想和天书阁动手？”

赤霄长老冷笑。

“动手又如何？”

沈惊鸿身上气息涌动。

化神境后期的威压弥漫开来，整个大殿都笼罩在强大的气场中。

“惊鸿。”

玄清真人开口，“不要冲动。”

沈惊鸿哼了一声，收起气息。

“赤霄长老。”

玄清真人看着赤霄长老，“你想带走苏言，总要有个理由吧？”

“理由？”

赤霄长老道，“苏言杀害我天书阁多名长老，这个理由够不够？”

“证据呢？”

玄清真人道，“空口无凭，你想带走人就带走人，当我万语宗是什么？”

赤霄长老脸色阴沉。

他没想到万语宗的态度会这么强硬。按照他的预想，万语宗应该会妥协才对。

“好。”

赤霄长老道，“既然如此，本座就给你们一个机会。”

他看着苏言，“苏言，本座给你一个公平对决的机会。只要你能接下本座三招，本座立刻走人。”

大殿安静了一瞬。

化神境巅峰对阵通玄境二重，这依然是不公平的对决。

“三招太多了。”

苏言开口，“一招足矣。”

此言一出，满场皆惊。

“苏言！”

白云子低喝。

“师尊，弟子有信心。”

苏言道。

赤霄长老看着苏言，眼中闪过一丝怒意。

“小子，你很狂。”

他道，“希望你有狂的资本。”

“长老。”

苏言道，“请吧。”

万语宗，山门外。

这里是宗门专门设立的决斗场，平时供弟子们切磋用。

此时，决斗场周围已经聚集了无数弟子。他们都是听说动静赶来的，想看看这场不对等的对决。

“苏言……”

周林站在人群中，脸色担忧。

他身边站着林诗诗和韩立，两人都是面色复杂。

“韩立。”

林诗诗低声道，“你觉得苏言能接下那一招吗？”

“极为艰难。”

韩立摇头，“化神境巅峰和通玄境二重之间，有巨大差距。即便苏言再强，想接下这一招也极为困难。”

“是吗？”

林诗诗喃喃道，眼中闪过一丝异色。

决斗场上，苏言和赤霄长老相对而立。

“小子。”

赤霄长老看着苏言，“本座给你一个先出手的机会。”

“不必。”

苏言道，“长老请。”

赤霄长老眼中闪过一丝冷意。

“那本座就不客气了。”

他身上气息涌动，一掌拍出。

这一掌看似平淡，但蕴含着毁天灭地的力量。化神境巅峰的随手一击，就能让山河崩裂。

“凝！”

苏言心中轻喝。

识海中，三大符文同时运转。

“凝”字诀定住空间，“破”字诀粉碎法则，“封”字诀封锁生机。

三击合一，化为最强的一击。

“轰！”

一声巨响，整个决斗场都颤抖起来。

烟尘散去，场上出现了两个人。

苏言还站着。

赤霄长老也站着，但他的脸色苍白，嘴角溢出一丝鲜血。

“你……”

赤霄长老看着苏言，眼中满是不可置信。

那一击，他竟然受伤了。

“长老承让。”

苏言淡淡道。

赤霄长老沉默片刻。

“好，很好。”

他道，“本座记住你了。”

说完，他转身离去。

天书阁的人立刻跟上，眨眼间就消失在视线中。

整个决斗场陷入了死寂。

“苏言……”

不知道是谁率先开口，声音颤抖。

“苏言！”

“苏言！”

欢呼声此起彼伏，响彻云霄。

这一战，苏言向整个万语宗证明了自己的实力。

通玄境二重，一招击退化神境巅峰。

这在整个修炼史上，都是前所未有的壮举。
