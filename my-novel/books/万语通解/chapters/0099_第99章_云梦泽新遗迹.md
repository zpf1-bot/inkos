# 第99章 第99章 云梦泽新遗迹

万语宗，藏经阁三层。

苏言盘膝而坐，周身气息内敛。识海中，七彩符文缓缓旋转，三百丈神识如潮水般涌动，每一次运转都带起细微的法则波动。

《天阙语》第三层已经修炼了半月，距离入门只差临门一脚。

“凝。”

他心中默念，手掌轻翻，一缕淡金色光芒在指尖凝聚。这是“凝”字的进阶运用，不仅能凝固对手的攻击，更能短暂凝固空间。

当然，以他现在的境界，只能凝固一个呼吸的时间。

“破。”

第二字出口，金光化作一道细线激射而出，击中前方的玉简。玉简完好无损，但内部结构已经被震碎。

“封。”

第三字落下，那道细线在空中炸开，化作无数金色符文，将玉简包裹。片刻后，符文消散，玉简已经消失不见。

这是言出法随三击的进阶运用——将“凝、破、封”三击合一，威力倍增。

但消耗也极大。以他现在的神识，最多只能使用两次。

苏言睁开眼，感受了一下体内的变化。神识已经达到三百零五丈，瞬移距离也增加到四十七丈。

距离突破三重，还差得远。

但境界已经彻底稳固，根基扎实。

“看来修炼遇到瓶颈了。”

一个苍老的声音从身后传来。

苏言转头，沈惊鸿不知何时出现在门口。

“弟子见过太上长老。”

苏言起身行礼。

“不必多礼。”

沈惊鸿走进来，目光落在苏言身上，带着几分审视。

“老夫看得出，你的积累已经足够，但想要突破三重，需要一个契机。”

“什么契机？”

苏言问道。

“战斗。”

沈惊鸿道，“或者……机遇。”

“弟子明白。”

苏言点头。

修炼到了他这个境界，闭门造车已经不够了。需要出去走走，寻找突破的契机。

“长老今日来，是有其他事？”

苏言问道。

沈惊鸿来藏经阁，一般是指导他修炼。但今日身上带着几分慎重，显然是有要事。

“云梦泽那边有新消息。”

沈惊鸿也不隐瞒，“三日前，云梦泽深处出现异象。似乎是……又一个遗迹。”

“遗迹？”

苏言心中一动。

云梦泽的遗迹，他之前探索过多次。从最初的古语言学院遗址，到后来的七彩莲空间，每一次都有重大收获。

“知道是什么遗迹吗？”

“还不确定。”

沈惊鸿道，“但各方势力都已经收到消息。隐脉、天书阁、散修联盟……都在往云梦泽赶。”

苏言皱眉。

又是隐脉。

自从上次遗迹之行后，隐脉似乎盯上了他。每次遗迹现世，都有隐脉的身影。

“宗门打算怎么处理？”

苏言问道。

“掌门的意思是，先派人去探查情况。”

沈惊鸿道，“如果遗迹有价值，再组织队伍深入探索。”

“谁去？”

苏言问道。

“云梦泽探索，向来是执法堂负责。”

沈惊鸿道，“但这次……老夫想让你去。”

“我？”

苏言愣了一下。

“不错。”

沈惊鸿道，“你的战力已经到了瓶颈，需要契机突破。遗迹，是最好的试炼场。”

“老夫会安排赵德全带队，另外再派两名化神境长老暗中保护。”

暗中保护……

苏言心中了然。

这是宗门对他的重视，也是对他的保护。

毕竟，天书阁的聚道境强者，随时可能出手。

“好。”

苏言点头，“弟子什么时候出发？”

“明日一早。”

沈惊鸿道，“你今晚准备一下，把该带的丹药符箓都带上。”

“是。”

沈惊鸿转身要走，又停下来。

“对了。”

他道，“林诗诗那边传来消息，想见你一面。”

“她？”

苏言皱眉。

“她没说是什么事？”

“没说。”

沈惊鸿道，“但她说，是关于韩立的消息。”

韩立……

苏言眼中闪过一丝冷意。

两年后的约定，还没有到履行的时候。韩立经脉恢复突破三重，修炼噬灵诀第四层，战力大增。但对他来说，还构不成威胁。

“弟子知道了。”

他道，“等从云梦泽回来再说。”

沈惊鸿点头，离开。

//

当晚，苏言没有继续修炼，而是清点了一下储物戒指中的资源。

灵石：三万七千有余。

符箓：金刚符×3、疾风符×3、敛息符×3。

丹药：玉露丸×3、破境丹×1。

特殊物品：万语之书碎片×7、化神境传承玉简×1、万佛城布防图×1、空间古字使用次数×2。

底牌不少，但面对聚道境强者，还是不够看。

“四年……”

苏言喃喃道。

四年后万语之祖苏醒，他必须在那天之前，拥有足够的自保之力。

不仅要救父亲，还要阻止隐脉的阴谋。

“修炼还是太慢。”

他摇头道。

如果能再获得一次传承，或者找到什么天材地宝，或许能缩短突破的时间。

“遗迹……”

苏言眼中闪过一丝期待。

希望这次的遗迹，能给他带来惊喜。

//

第二日清晨，万语宗山门。

赵德全已经等在那里，身后跟着十几名弟子，都是执法堂的精英。

“苏言。”

赵德全看到苏言，点了点头。

“赵长老。”

苏言还礼。

“这次探索，以你为主。”

赵德全道，“我带队，但你负责判断遗迹的价值。”

“明白。”

苏言道。

云梦泽遗迹，他经验丰富。什么样的遗迹有价值，什么样的遗迹是陷阱，他一眼就能看出来。

“出发。”

赵德全下令。

一行人御剑而起，直奔云梦泽。

//

云梦泽深处，距离万语宗千里之遥。

苏言站在一座山峰上，俯瞰着下方的山谷。

三天前，这里出现了异象。天空呈现七彩霞光，持续了整整一个时辰。各方势力闻讯而来，已经在这里扎营。

“隐脉的人到了。”

赵德全低声道。

苏言顺着他的目光看去。

山谷另一侧，搭建着数十座帐篷，帐篷上印着灰色的莲花纹饰——那是隐脉的标志。

“有多少人？”

“不下五十。”

赵德全道，“为首的是灰老的师弟，灰羽。”

灰羽……

苏言想起那个化神境巅峰的强者。

之前在云梦泽深处，就是灰羽带队拦截他。虽然最后被击退，但此人实力极强，不可小觑。

“天书阁呢？”

“天书阁的人还没到。”

赵德全道，“但应该快了。”

正说着，又有一队人马从远处飞来。

“是散修联盟。”

苏言认出了来人的服饰。

散修联盟，由各地散修组成的松散组织，实力参差不齐。但能在云梦泽存活的散修，都有两把刷子。

“先下去。”

赵德全道。

一行人降落在山谷中，引起了其他势力的注意。

“是万语宗的人。”

“为首的是赵德全，通玄境巅峰。”

“那个年轻人是谁？竟然走在赵德全前面？”

议论声响起。

苏言没有在意这些目光，而是仔细观察着山谷。

山谷中央，是一片废墟。残垣断壁间，隐约可以看到一些建筑物的影子。

“是古遗迹。”

苏言判断道。

看建筑风格，至少是数万年前的产物。

“能看出是什么遗迹吗？”

赵德全问道。

苏言没有回答，而是闭上眼，神识扩散开来。

三百零五丈的神识，如潮水般蔓延，将整个山谷覆盖。

有用。

没有禁制，没有陷阱。

但废墟深处，似乎有什么东西，在吸引着他。

“万语之书的气息……”

苏言心中一动。

他身上的七块碎片，同时震颤了一下。

“这里有万语之书的碎片？”

他睁开眼睛，眼中闪过一丝惊讶。

“不对。”

他摇头，“不是碎片，是……万语之书的本体？”

不可能。

万语之书已经碎成七块，本体早已消散。

“还是说……”

苏言心中闪过一个念头。

“走，进去看看。”

他率先走向废墟。

//

废墟深处，是一座崩塌的大殿。

苏言站在大殿中央，目光落在墙壁上。

那里，刻着无数古老的文字。

“是古语言。”

苏言心中震动。

这些文字，和他在云梦泽深处获得的古语言传承同源。

“难道是……”

他走近墙壁，仔细查看。

这些文字，似乎记载着某种功法。

“语言法则的运用……”

苏言喃喃道。

这是一种全新的运用方式，和他之前学的都不同。

“创造……”

他忽然明白过来。

这不是普通功法，而是关于“创造”语言的高深法门。

万语之书虽然是语言法则的载体，但真正的核心，是创造语言的能力。

“难道万语之书还没有完全碎裂？”

苏言心中震动。

如果他能在这里获得更多关于“创造”语言的感悟，实力必定能更上一层楼。

“必须阻止隐脉。”

他立刻做出判断。

如果让隐脉先获得这些传承，实力会大幅提升。日后对付起来，会更加困难。

“赵长老。”

苏言转身道，“我要留在这里修炼。”

“修炼？”

赵德全愣了一下。

“这里有古语言传承，对我很重要。”

苏言道，“请赵长老帮我护法。”

赵德全犹豫了一下。

这里是遗迹，随时可能有危险。但他也知道，苏言的修炼到了关键时期，迫切需要突破的契机。

“好。”

他点头道，“我会在外面守着。”

“多谢。”

苏言转身，面向墙壁，闭上眼。

识海中，七彩符文开始旋转。

这一次，它们不再是各自运转，而是开始融合。

//

就在苏言开始修炼时，山谷另一侧，隐脉的营地。

“万语宗的人到了。”

一名灰袍人汇报道。

“为首的是谁？”

灰羽问道。

“赵德全，还有一个年轻人。”

“什么年轻人？”

灰羽皱眉。

“好像是……苏言。”

灰羽脸色大变。

“苏言？他也来了？”

“没错。”

灰袍人道，“他进了遗迹，现在正在里面修炼。”

“修炼？”

灰羽冷笑。

“这倒是他的风格。”

他起身，“走，我们也进去。”

“可万语宗的人……”

“怕什么。”

灰羽道，“遗迹还没开启，各凭本事。”

//

遗迹中，苏言对外界一无所知。

他的心神，全部沉浸在墙壁上的古文字中。

这些文字，讲述的是语言法则的终极运用——创造。

所谓创造，不是简单地发明新语言，而是从根本上，改变语言的本质。

“以我之血，铭刻法则……”

“以我之神，沟通天地……”

“以我之语，创造万物……”

一个个玄奥的符文，在苏言识海中浮现。

他的神识，开始飞速增长。

三百一十丈……

三百一十五丈……

三百二十丈……

仅仅是片刻功夫，神识就增长了十五丈。

这已经超越了正常的修炼速度。

“这就是创造语言的门槛吗？”

苏言心中震动。

按照墙壁上的记载，语言分为三个层次：解析、运用、创造。

解析，是理解语言背后的法则。

运用，是利用语言调动法则。

创造，是从无到有，构建全新的法则。

他现在处于“运用”的巅峰，即将踏入“创造”的门槛。

一旦真正踏入创造境界，实力会发生质的飞跃。

“凝！”

苏言心中低喝。

这一次，他不是用“凝”字来凝固对手的攻击，而是尝试创造一个新的“凝”字。

一个，完全不同的“凝”字。

识海中，七彩符文疯狂旋转。

某一刻，仿佛有什么东西破碎了。

一个新的符文，在识海中央诞生。

这个符文，和之前的“凝”字完全不同。它是苏言自己创造的，蕴含着全新的法则。

“创造……”

苏言睁开眼，眼中闪过一丝喜色。

他终于迈出了第一步。

创造语言的第一步。

神识：三百三十丈。

瞬移：四十八丈。

战力：彻底稳固在化神境后期巅峰，距离化神境巅峰只差一线。

“这就是创造的力量吗？”

苏言握紧拳头。

仅仅是一个全新的符文，就让他的实力提升了这么多。

如果能创造更多……

“有人来了。”

他脸色一动。

神识探查到，两道强大的气息，正在接近。

“是灰羽。”

苏言起身。

还有另一道气息，同样强大。

“化神境巅峰。”

苏言判断道。

隐脉的底蕴，果然深厚。

“看来要有一战了。”

他握紧拳头，眼中战意昂然。

创造语言后，他还没有真正动过手。

正好借此机会，检验一下实力。

//

遗迹大殿入口。

灰羽带着一名灰袍老者，步入其中。

“苏言！”

灰羽看到苏言，眼中闪过一丝杀意。

“灰羽。”

苏言转身，淡然面对。

“没想到你真的敢来。”

灰羽冷笑道，“真当我们隐脉是吃素的？”

“遗迹而已，各凭本事。”

苏言道。

“各凭本事？”

灰羽大笑，“好，那本座就来看看，你有什么本事。”

他一步踏出，化神境巅峰的气息，扑面而来。

“小心。”

赵德全的声音从外面传来。

但已经晚了。

灰羽动手的同时，苏言也动了。

“凝！”

苏言低喝。

一个全新的“凝”字，从他手中飞出。

这个字，和之前的完全不同。蕴含着创造的力量。

灰羽脸色大变。

他想躲，但已经来不及了。

“凝”字击中他的胸口，狂暴的法则力量爆发。

灰羽整个人倒飞出去，撞在大殿墙壁上。

“一击。”

苏言淡淡道。

灰羽爬起来，嘴角溢血。

“你……”

他眼中满是不可置信。

刚才那一击，竟然伤到了他。

“不可能！”

灰羽咆哮道，“你只是通玄境二重，怎么可能是我的对手？”

“井底之蛙。”

苏言摇头。

他现在已经不是之前的他了。

创造语言的力量，足以碾压化神境巅峰。

“灰羽，退下。”

那个一直没有说话的灰袍老者开口了。

“大长老？”

灰羽脸色大变。

“退下。”

灰袍老者重复道。

灰羽咬牙，退到一旁。

“小友。”

灰袍老者看着苏言，眼中闪过一丝忌惮。

“老夫隐脉大长老，灰无尽。”

“自创语言……老夫佩服。”

苏言脸色平静，心中却是警惕。

这个灰无尽的气息，比灰羽强大太多。

至少是化神境巅峰巅峰，甚至可能已经触及聚道境的门槛。

“过奖。”

苏言道。

“小友。”

灰无尽道，“这座遗迹，对我隐脉很重要。能否给个面子，让给我们？”

“不能。”

苏言道。

灰无尽叹气。

“那就抱歉了。”

他身上的气息，开始攀升。

化神境巅峰……

然后，突破了。

聚道境！

苏言脸色大变。

聚道境强者，竟然提前降临了。

“小友小心！”

赵德全的声音传来。

与此同时，两道身影从外面冲进来。

是暗中保护苏言的化神境长老。

但他们只是化神境，面对聚道境，没有胜算。

“走！”

苏言当机立断。

现在不是硬拼的时候。

“凝！”

他再次使用创造语言，凝固空间。

然后，瞬移！

四十八丈的距离，瞬间跨越。

“想走？”

灰无尽冷笑。

他一步踏出，竟然追了上来。

聚道境的实力，太过恐怖。

“封！”

苏言反手一掌。

“封”字落下，灰无尽的速度果然一顿。

但只是片刻，他就挣脱了。

“空间古字……”

灰无尽眼中闪过一丝贪婪。

“交出来，饶你不死。”

苏言没有回答，而是继续瞬移。

三丈……

两丈……

一丈……

终于，他冲出了遗迹。

“追！”

灰无尽下令。

但万语宗的两位长老，已经挡在了遗迹门口。

“苏言，快走！”

赵德全喊道。

苏言没有犹豫，直接御剑而起，返回万语宗。

//

万语宗，执法堂。

苏言站在大殿中，脸色苍白。

刚才一战，虽然成功逃脱，但消耗极大。

创造语言虽然强大，但对上真正的聚道境，还是不够看。

“灰无尽……”

他喃喃道。

隐脉竟然提前出动了聚道境强者，这出乎所有人的意料。

“看来，局势要变了。”

沈惊鸿的声音传来。

他走进大殿，看着苏言，眼中带着几分复杂。

“你的实力，又提升了？”

“侥幸。”

沈惊鸿叹息。

“创造语言，果然恐怖。”

他之前还担心苏言无法在一年内突破三重，但现在看来，他的担心是多余的。

“长老。”

苏言道，“隐脉的聚道境强者已经出手，宗门要早做准备。”

“老夫知道。”

沈惊鸿道，“掌门已经知道了这件事，正在召集各峰首座议事。”

“另外……”

他看着苏言，“你创造语言的事情，已经传出去了。”

苏言心中一沉。

这个消息，会让隐脉更加忌惮，也会让天书阁更加疯狂。

“接下来，你有什么打算？”

沈惊鸿问道。

苏言沉默片刻。

“继续修炼。”

他道，“一年后，我要突破三重。”

“然后，宰了韩立。”

沈惊鸿点头。

“好。”

他道，“宗门会全力支持你。”

“起来吧。”

灰无尽道。

“那苏言，确实很强。”

“他刚才那一击，已经不弱于聚道境初期。”

“什么？”

灰羽脸色大变。

“他只是通玄境二重，怎么可能有这种实力？”

“创造语言的力量，不是你能够理解的。”

灰无尽道。

“传令下去。”

他继续道，“密切关注苏言的动向。另外，遗迹的传承，不能让万语宗得到。”

“是。”

灰羽起身，退下。

万语宗，洞府。

苏言盘膝而坐，消化着今天的收获。

虽然差点丧命，但他也验证了创造语言的威力。

“聚道境……”

他喃喃道。

以他现在的实力，对上聚道境初期，有一战之力。但对上聚道境中期，还是没有胜算。

“必须更快突破。”

他握紧拳头。

识海中，新创造的符文缓缓旋转，散发着淡淡的光芒。

这是属于他的力量。

“四年……”

他眼中闪过一丝坚定。

四年后万语之祖苏醒，他必须在那天之前，拥有足够的实力。

否则，不仅父亲救不出来，整个世界都会陷入危机。

“修炼。”

苏言闭上眼。

识海中，七彩符文和新创造的符文，同时运转。

神识，开始缓慢增长。

距离突破，又近了一步。

山风吹过，带来阵阵寒意。

一场更大的风暴，正在酝酿。
