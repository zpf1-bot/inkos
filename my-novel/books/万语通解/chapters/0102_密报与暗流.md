# 第102章 密报与暗流

万语宗，内门洞府。

苏言盘膝而坐，周身气息平稳。击败赤霄长老已经过去三天，他的境界彻底稳固在通玄境二重。

识海中，**三百三十丈**的神识如潮水般涌动。荒原语符文已经不再是当初的雏形，而是形成了一个完整的体系。小成境界，意味着他已经掌握了荒原语的核心法则。

“以血为誓、以骨为铭……”

苏言心中默念荒原语的口诀。

他能感觉到，自己的气血比之前强横了数倍。这三个月的气血消耗，不仅没有削弱他的身体，反而让他的肉身更加凝实。

“这就是荒原语的独特之处……”

苏言睁开眼，眼中闪过一丝精芒。

荒原语和其他语言不同，它是以气血为根基。每一次施展，都会消耗使用者的气血。但反过来，气血越强，荒原语的威力就越大。

“可惜，荒原语只能作为杀手锏，不能常用。”

苏言心中惋惜。

气血消耗过大，是荒原语最大的限制。除非能找到补充气血的方法，否则这门语言只能用來关键时刻保命。

“苏言。”

洞府外传来周林的声音。

苏言起身，打开禁制。

周林站在外面，脸色有些复杂。

“出什么事了？”

苏言问道。

“荒原部族来人了。”

周林道，“就在刚才，已经进入宗门。”

苏言心中一动。

荒原部族这个时候派人来，难道是为了那天的事？

“我知道了。”

苏言点头，“在哪？”

“议事大殿。”

周林道，“掌门让你过去。”

//

万语宗，议事大殿。

苏言走进大殿，发现气氛比想象中凝重。

为首的还是掌门玄清真人，左右分别是沈惊鸿和白云子。在他们对面，坐着一名身穿白袍的老者。

那老者看起来六七十岁，面容消瘦，但一双眼睛格外明亮。他的气息内敛，苏言竟然看不透他的境界。

化神境以上。

苏言心中判断。

“苏言来了。”

玄清真人道，“这位是荒原部族的巴图尔长老。”

“巴图尔长老。”

苏言点头。

“苏公子。”

巴图尔看着苏言，眼中闪过一丝审视，“果然年轻有为。”

“长老过奖。”

苏言淡淡道。

“苏言。”

玄清真人开口，“巴图尔长老这次来，是有要事相商。”

“什么要事？”

苏言问道。

巴图尔看了玄清真人一眼，得到示意后，才缓缓开口。

“苏公子可知，我族为何迁徙？”

“不是说为了躲避更强的敌人？”

苏言道。

“不错。”

巴图尔点头，“但苏公子可知，那敌人是谁？”

苏言摇头。

他确实好奇。能让整个荒原部族舍弃领地大举迁徙的对手，绝对不简单。

“是一个人。”

巴图尔道，“或者說，是一个已经不属于人范畴的存在。”

大殿安静下来。

“什么存在？”

沈惊鸿开口。

“沙漠死神。”

巴图尔道，“那是一个被封印在上古时期的恐怖存在。我族世代镇守封印，防止它苏醒。但就在一年前，封印出现了裂痕。”

“沙漠死神……”

玄清真人皱眉，“老夫从未听说过。”

“掌门自然没听说过。”

巴图尔道，“因为这个消息，被列为荒原部族最高的机密。只有大祭司和几位长老知道。”

“那你现在为何说出来？”

白云子问道。

“因为隐瞒不住了。”

巴图尔苦笑，“沙漠死神的气息已经泄露，最多三年，它就会彻底苏醒。到时候，整个西域都会变成人间炼狱。”

大殿陷入沉默。

这个消息太震撼了。一个被封印的上古存在，即将苏醒。这意味着什么，不言而喻。

“你们荒原部族，有没有办法阻止？”

玄清真人问道。

“有。”

巴图尔道，“但需要帮助。”

“什么帮助？”

“沙漠死神是被语言法则封印的。”

巴图尔看着苏言，“能解开封印的，也只有语言法则。”

“你是说……”

玄清真人看向苏言。

“不错。”

巴图尔道，“苏公子获得了古语言传承，能够创造新的语言字符。如果他能参与封印加固仪式，成功率至少有五成。”

“五成？”

苏言开口，“另外五成呢？”

巴图尔沉默片刻。

“失败的后果，是封印彻底崩塌，沙漠死神提前苏醒。”

他道，“所以，老夫才会亲自上门请求。”

苏言心中盘算。

这件事风险太大，一个不小心就会万劫不复。但如果成功，好处也是显而易见的。

首先，能再次接触沙漠死神这种上古存在，对他的语言法则领悟绝对有巨大帮助。其次，如果能加固封印，他在荒原部族中的地位将截然不同。

最重要的是，荒原部族掌握着荒原语的全部传承。如果能借此机会获得完整的荒原语，他的战力将再上一个台阶。

“长老。”

苏言开口，“我需要时间考虑。”

“可以。”

巴图尔道，“但时间不多。沙漠死神的气息正在不断增强，最多一年，封印就会崩溃。”

“一年……”

苏言喃喃道。

一年后天书阁的聚道境强者就会来袭，如果再加上沙漠死神……

“先等我的消息。”

苏言道。

“好。”

巴图尔起身，“老夫在荒原部族驻地等候苏公子的好消息。”

//

离开议事大殿，苏言直接去找白云子。

“师尊。”

苏言道，“你觉得这件事可信吗？”

“九成九是真的。”

白云子道，“沙漠死神的存在，为师曾在一份古籍中看到过零星记载。”

“是什么来历？”

苏言问道。

“不太清楚。”

白云子摇头，“只知道它是被万语之祖亲手封印的。”

“万语之祖？”

苏言心中一动。

又是万语之祖。

四年后万语之祖苏醒，现在又出现了沙漠死神被万语之祖封印的线索……

这些事件之间，是否有什么关联？

“先不要想太多。”

白云子道，“当前最重要的是应对天书阁的聚道境强者。三个月的时间，说长不长，说短不短。”

“弟子明白。”

苏言道。

“对了。”

白云子道，“林诗诗来找过你两次。”

“她有什么事？”

“没说。”

白云子道，“但她看起来很着急。你可以去见见她。”

//

万语宗，后山。

这里有一片竹林，平日里很少有人来。

苏言按照约定来到这里，发现林诗诗已经等在了竹林中。

她还是穿着那件白色长裙，乌黑的长发披散在肩上，整个人看起来清丽脱俗。但此刻，她的脸上带着一丝凝重。

“你来了。”

林诗诗转身看着苏言。

“听说你找我两次。”

苏言道，“什么事？”

“借一步说话。”

林诗诗道。

两人走到竹林深处，确认周围没有人后，林诗诗才开口。

“韩立突破通玄境三重了。”

她道。

“然后呢？”

苏言淡淡道。

“他现在的战力，应该已经接近化神境初期。”

林诗诗道，“两年后的约定，你还有把握吗？”

“怎么，你在担心我？”

苏言看着林诗诗。

林诗诗沉默片刻。

“我只是提醒你。”

她道，“韩立修炼的是噬灵诀禁术，威力远超普通功法。再加上他经脉恢复后，根基比之前更稳固。”

“我知道了。”

苏言道，“还有其他事吗？”

“荒原部族的事，你打算怎么办？”

林诗诗问道。

“还没决定。”

苏言道，“你怎么知道的？”

“我自然有我的渠道。”

林诗诗道，“苏言，我再提醒你一件事。”

“说。”

“韩立背后的人，不是天书阁。”

林诗诗看着苏言，“是隐脉。”

苏言心中一凛。

隐脉……

那个企图唤醒万语之祖的组织，竟然和韩立勾结在一起了？

“你说的是真的？”

苏言问道。

“我没有骗你的必要。”

林诗诗道，“韩立经脉恢复后，第一个找的就是隐脉的人。他们达成了一项协议，具体内容我不知道，但我知道隐脉答应帮韩立杀掉你。”

苏言沉默。

隐脉的势力有多强大，他之前已经见识过了。聚道境强者都有数位，如果不是忌惮万语之祖的虚影，他可能早就死了。

“现在你明白了吧？”

林诗诗道，“你的敌人不只是天书阁，还有隐脉。两年后的约定，韩立身后站着的可能是整个隐脉。”

“那又如何？”

苏言道，“兵来将挡，水来土掩。”

林诗诗看着苏言，眼中闪过一丝复杂。

“我言尽于此。”

她道，“你好自为之。”

说完，她转身离开。

苏言站在竹林中，思考着林诗诗提供的信息。

隐脉和韩立勾结，这在他的意料之外。但仔细想想，又在清理之中。韩立经脉尽断，如果不是隐脉帮忙，不可能恢复得这么快。

“看来需要加快进度了。”

苏言心中盘算。

天书阁的聚道境强者、隐脉的威胁、韩立的复仇、沙漠死神即将苏醒……这些事情交织在一起，让他感到前所未有的压力。

但压力也是动力。

“如果能在一年内突破到通玄境三重，甚至是四重……”

苏言心中闪过一个念头。

通玄境二重到三重，需要的积累比之前多得多。但如果加上荒原部族的帮助，或许可以加快这个过程。

“荒原语……”

苏言喃喃道。

完整的荒原语传承对他吸引力太大。如果能获得，对他的实力将是一次质的飞跃。

“看来那件事需要提上日程了。”

苏言做出决定。

//

回到洞府，苏言立刻给巴图尔传讯，表示愿意参与封印加固仪式。

消息很快传回，巴图尔表示欢迎苏言随时前往荒原部族驻地。

但苏言没有立刻动身。

因为他知道，现在最重要的是稳固境界，应对三个月后的聚道境强者。

“荒原语小成，让我有了抗衡化神境巅峰的底气。”

苏言心中分析，“但面对聚道境，还远远不够。”

聚道境是“以言合道”的境界，已经初步掌握了言出法随的能力。这种存在，一句话就能定人生死，威力远超化神境。

“除非……”

苏言想到一个可能。

如果能把荒原语和“凝”字结合起来，发挥出创造语言的真正威力，或许能和聚道境抗衡一二。

“但这需要时间。”

苏言皱眉。

三个月的时间，说长不长，说短不短。如果能在天书阁强者到来之前突破到通玄境三重，生存的希望会大很多。

“先修炼着，走一步看一步。”

苏言收回思绪，闭上眼睛。

识海中，**三百三十丈**的神识如潮水般涌动。荒原语符文在神识的温养下，缓缓旋转。

距离突破，又近了一步。

//

一个月后。

万语宗，某处修炼密室。

苏言盘膝而坐，周身气息澎湃。

这一个月，他几乎没有离开密室一步。不停地修炼、感悟、突破就是为了在最短的时间内提升实力。

识海中，神识已经突破到了**三百四十丈**。

“还是不够……”

苏言睁开眼，眼中闪过一丝失望。

通玄境二重到三重，需要的神识量远超他的预期。一个月苦修，只增加了十丈神识，距离突破还有很大一段距离。

“看来常规修炼不行。”

苏言心中盘算。

要么去寻找遗迹、灵药，要么去挑战更强的对手，在生死之间寻求突破。

“遗迹……”

苏言想到云梦泽的新遗迹。

根据之前的消息，那里面似乎蕴含着空间法则的传承。如果能再获得一次类似的传承，或许能突破当前的瓶颈。

“但天书阁的人正在虎视眈眈……”

苏言有些犹豫。

以他现在的实力，遇到化神境巅峰有一战之力。但如果遇到聚道境，只有逃命的份。

“先巩固境界，然后去云梦泽碰碰运气。”

苏言做出决定。

就在他准备离开密室的时候，禁制被触动了。

“苏言。”

是周林的声音。

“什么事？”

苏言打开禁制。

“宗门传来消息。”

周林道，“云梦泽深处发现了新的遗迹，据说有空间法则的传承。”

苏言心中一动。

竟然这么巧？

“什么时候发现的？”

“就在刚才。”

周林道，“宗门已经组织队伍，明早就出发。”

“都有哪些人？”

“白发长老带队，还有十名核心弟子。”

周林道，“你也被选中了。”

苏言沉默片刻。

刚想瞌睡就有人送枕头，看来这趟云梦泽之行是免不了了。

“好。”

苏言点头，“我准备一下。”

//

一夜无话。

第二天清晨，万语宗的队伍准时出发。

白发长老还是老样子，看起来仙风道骨，但身上的气息却异常凌厉。跟他一起的，还有十名核心弟子，都是通玄境以上的强者。

苏言站在队伍中，感受着四周的目光。

虽然他只是通玄境二重，但论战力，在场的没有人是他的对手。这种实力带来的尊重，让他有一种说不出的感觉。

“苏言。”

白发长老走到苏言身边，“这次遗迹探索，你有什么看法？”

“弟子不敢妄言。”

苏言道。

“但说无妨。”

白发长老道。

苏言沉默片刻，才开口。

“弟子觉得，这个遗迹出现得太巧了。”

他道，“正好在荒原部族消息传来的同时，云梦泽就出现了新遗迹。这里面的关联，值得深思。”

白发长老看了苏言一眼，眼中闪过一丝赞赏。

“你说的不错。”

他道，“宗门也在怀疑，这是天书阁或者隐脉的陷阱。”

“那为何还要我们来？”

有弟子问道。

“即便是陷阱，也要闯一闯。”

白发长老道，“如果真的有空间法则传承落在敌人手里，对我们更不利。”

众人沉默。

确实如此。

“小心为上。”

白发长老道，“到时候见机行事。”

队伍沉默前行，目标直指云梦泽深处。

（本章完）
