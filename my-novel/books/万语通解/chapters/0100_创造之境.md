# 第100章 创造之境

万语宗，苏言洞府。

晨光透过窗棂，在地面投下斑驳的光影。苏言盘膝而坐，周身气息平稳，识海中那枚新生的“凝”字符文缓缓旋转，散发着淡淡的金芒。

创造语言。这三个字在他心中沉甸甸的。不同于之前的“凝”字是古语言中本就存在的符文，这个全新的“凝”字完完全全是由他亲手创造，蕴含着独属于他的法则印记。

“凝！”

苏言心中轻喝。

识海中的符文骤然亮起，一缕淡金色光芒在指尖凝聚。他能感觉到，这缕光芒与之前的“凝”字有本质区别——之前的“凝”字是借用法则，而这一次，是创造法则。

这就是语言法则的第三个层次，创造。

“以我之血，铭刻法则……以我之神，沟通天地……以我之语，创造万物……”

墙壁上的古文字在脑海中浮现，那是云梦泽遗迹中记载的语言法则终极运用。虽然他只记下了部分，但已经足以让他窥见创造境界的门径。

“可惜，只是入门。”

苏言睁开眼，结束了修炼。

创造语言和解析、运用不同，需要对语言法则有极深的理解。他现在刚刚迈过门槛，距离真正掌握还有很长的路。

但即便只是入门，威力已经足以伤到化神境巅峰的灰羽。

“灰羽……”

苏言喃喃道。

灰羽是隐脉的长老化神境巅峰，在之前的云梦泽遗迹中，此人曾多次拦截他。上一次见面，此人还能和他正面抗衡，而现在，创造语言一出，此人已经接不住他一击。

这就是创造的力量。

“苏言。”

一个声音从洞府外传来。

苏言起身，打开禁制。

周林站在外面，手里提着一个食盒。

“周林？”

苏言有些意外。

“给你带了点吃的。”

周林笑道，“你闭门修炼三天了，连饭都没吃。”

“三天？”

苏言愣了一下。

他感觉只过了一会儿，没想到已经三天了。

“进来吧。”

苏言让开身体。

周林走进洞府，将食盒放在桌上。

“云梦泽那边的情况怎么样了？”

苏言问道。

云梦泽新遗迹的事，已经过去三天。他返回宗门后就开始闭关，还没有关心后续发展。

“隐脉的人还在那，但遗迹已经崩塌了。”

周林道，“灰羽亲自带人搜查了三天，什么都没找到。”

“那座遗迹的传承，被我得了。”

苏言道。

“果然。”

周林并不意外，“宗门都在传，说你获得了古语言传承，实力大增。”

“传得这么快？”

苏言皱眉。

“事关重大，想不传开都难。”

周林道，“现在外面都在猜测，你突破到了什么境界。”

“通玄境二重。”

苏言道。

周林嘴角抽了抽。

若是其他人说通玄境二重，他不会有什么反应。但苏言这个通玄境二重，能把化神境巅峰按在地上摩擦。

“苏言，你老实告诉我。”

周林忍不住道，“你现在到底有多强？”

苏言沉默片刻。

“化神境内，应该没有对手。”

他斟酌着措辞，“聚道境初期，可以一战。聚道境中期，不是对手。”

周林倒吸一口凉气。

聚道境，那可是比化神境更高的境界。整个万语宗，有没有聚道境都是个问题。而苏言现在竟然说可以一战。

“变态。”

周林嘟囔道。

苏言没有反驳。他的战力确实已经到了一个极其夸张的地步。通玄境二重逆战聚道境，这在整个修炼史上都是罕见的。

“对了。”

周林想起什么，“林诗诗来找过你两次。”

“她？”

苏言皱眉。

林诗诗，那个神秘的女子。从第一次见面起，此女就表现得很不正常——她知道很多不该知道的东西，和隐脉似乎也有某种联系。

“她说什么了吗？”

“没有。”

周林道，“她只说等你出关，让她见一面。”

苏言想了想。

和林诗诗的两年之约还没有到履行的时候，韩立还活着，他们之间的交易也还没有完成。但此女三番两次来找他，显然不只是为了韩立的事。

“等我稳固境界，再见她。”

苏言道。

“好。”

周林点头，“我先去回复她。”

//

送走周林，苏言继续在洞府中修炼。

识海中，三百三十丈的神识如潮水般涌动。新创造的“凝”字符文和其他七彩符文交相辉映，散发着玄奥的气息。

“凝、破、封……”

苏言心中默念言出法随三击的法门。

这三击是他目前的底牌，每一击都有莫大的威力。尤其是“封”字，配合空间古字使用，足以暂时困住化神境巅峰强者。

但面对聚道境，还是不够看。

灰无尽只是聚道境初期，就能轻易挣脱他的“封”字。如果是聚道境中期，甚至聚道境后期，他连逃命都困难。

“四年……”

苏言睁开眼，眼中闪过一丝紧迫。

四年后万语之祖苏醒，他必须在那之前拥有足够的实力。不仅是救父亲，更要阻止隐脉的阴谋。

“荒原语……”

他忽然想起什么。

万语之书的碎片他已经集齐七块，短时间内应该不会再有碎片的消息。与其干等，不如去探索其他语言。

荒原语，是他目前还没有掌握的语种之一。

根据宗门记载，荒原语是草原部族的核心语言，和其他灵语有本质区别。如果能掌握荒原语，对他的语言法则领悟会有极大帮助。

“荒原部族……”

苏言喃喃道。

荒原部族位于西域，和万语宗一向井水不犯河水。但根据之前的消息，荒原部族最近似乎有异动。

“看来得找机会去一趟西域。”

苏言心中盘算着。

就在这时，洞府外的禁制被触动。

“苏言。”

是沈惊鸿的声音。

苏言起身，打开禁制。

沈惊鸿站在外面，身后还跟着两人。

“长老。”

苏言行礼。

“这两人你应该认识。”

沈惊鸿指着身后的两人。

苏言看去，是两名中年男子，身上气息内敛，但隐隐透露出强大的气息。

“是那两位暗中保护我的长老。”

苏言立刻认出来。

在云梦泽遗迹中，就是这两人挡住隐脉，让他有机会逃脱。

“老夫韩立。”

左边那中年男子道。

“老夫刘云。”

右边那中年男子道。

“原来是韩长老、刘长老。”

苏言再次行礼。

“不必多礼。”

沈惊鸿道，“进去说话。”

//

洞府内，四人围坐。

“云梦泽遗迹的事，你应该知道了。”

沈惊鸿开门见山，“隐脉的人还在那里，但遗迹已经崩塌，什么都没剩下。”

“便宜他们了。”

刘云道。

“遗迹的核心传承已经被我得到。”

苏言道，“隐脉就算把遗迹翻个底朝天，也找不到任何东西。”

“这就是老夫今日来找你的原因。”

沈惊鸿看着苏言，“创造语言的事，已经传出去了。”

苏言心中一沉。

“整个修炼界，现在都在传，说万语宗出了一个能创造语言的妖孽。”

沈惊鸿继续道，“天书阁那边，已经炸锅了。”

“天书阁什么反应？”

苏言问道。

“大长老亲自下令，不惜一切代价也要得到你。”

沈惊鸿道，“如果得不到，就地格杀。”

苏言冷笑。

天书阁和他之间的仇怨，已经无法化解。从一开始的暗杀，到现在的不死不休，双方早已是生死之敌。

“隐脉呢？”

苏言问道。

“灰无尽亲自出手了。”

沈惊鸿道，“这说明隐脉对你身上的古玉碎片志在必得。”

苏言点头。

他身上有七块万语之书碎片，每一块都蕴含着语言法则的碎片。隐脉想要唤醒万语之祖，这些碎片是必须的。

“大长老。”

苏言道，“弟子想知道，宗门对弟子到底是什么态度？”

沈惊鸿沉默了片刻。

“掌门的意思是，不惜一切代价保护你。”

他道，“你现在是万语宗最重要的弟子，没有之一。”

苏言心中一暖。

虽然他和万语宗之间没有太深的感情，但宗门对他的重视是认真的。

“多谢宗门。”

苏言道。

“先别急着谢。”

沈惊鸿道，“天书阁已经决定请动聚道境强者。”

苏言脸色微变。

聚道境强者，他目前还不是对手。

“预计多久？”

“半年。”

沈惊鸿道，“天书阁的底蕴非同小可，请动聚道境强者需要时间。半年是他们给出的底线。”

半年……

苏言心中盘算。

半年后，他必须拥有能和聚道境初期抗衡的实力。否则，只有死路一条。

“弟子明白。”

苏言道，“弟子会在这半年内突破三重。”

“三重不够。”

沈惊鸿道，“聚道境和化神境之间，有天壤之别。你必须突破化神境，才有可能抗衡聚道境。”

化神境……

苏言苦笑。

他从通玄境二重到化神境，还有很长的路要走。

“长老，弟子有一事相求。”

苏言道。

“说。”

“弟子想请宗门帮忙搜集荒原语的功法典籍。”

苏言道。

“荒原语？”

沈惊鸿皱眉，“你要荒原语做什么？”

“弟子想试试看，能不能解析荒原语。”

苏言道。

解析荒原语？

沈惊鸿三人对视一眼，眼中都闪过一丝惊讶。

万语通解的能力，他们都知道。但荒原语是草原部族的核心语言，和其他灵语有本质区别。其难度不知道比普通灵语高多少倍。

“你有把握？”

沈惊鸿问道。

“七成。”

苏言道。

实际上，他有十成把握。万语通解的能力摆在那里，只要接触到荒原语，他就能解析。

但七成已经足够了。

“好。”

沈惊鸿道，“老夫会让宗门全力搜集荒原语功法典籍。”

“多谢长老。”

苏言道。

//

送走沈惊鸿三人，苏言站在洞府门口，望着远方的天空。

天书阁、隐脉、韩立……一个又一个敌人浮现在脑海中。

但他没有退缩。

既然选择了这条路，就只能走下去。

“韩立……”

苏言眼中闪过一丝冷意。

两年之约，还没有到履行的时候。但此人对他的威胁，已经越来越大。

噬灵诀的诡异程度，超出他的预料。第一次经脉尽断后还能恢复，第二次也是如此。此人就像打不死的小强，一次次重新站起来。

“必须尽快提升实力。”

苏言握紧拳头。

他有预感，韩立此番突破三重只是个开始。如果放任下去，说不定真的会成为心腹大患。

“四年……”

他再次想到四年后的万语之祖苏醒。

四年后，不仅要救父亲，还要阻止隐脉的阴谋，更要面对天书阁的聚道境强者。

时间紧迫，容不得他有任何松懈。

“修炼。”

苏言转身回到洞府。

识海中，七彩符文和新创造的“凝”字同时运转，神识开始缓慢增长。

距离突破，又近了一步。

//

就在苏言闭门修炼时，万语宗某处。

林诗诗站在一座山峰上，俯瞰着整个宗门。

在她身后，站着两名灰袍人。

“小姐。”

其中一名灰袍人道，“苏言已经出关了。”

“我知道。”

林诗诗淡淡道。

“他现在实力大增，创造语言的能力已经入门。”

“小姐，此人对我隐脉威胁极大。”

另一名灰袍人道，“不如趁现在……”

“现在还不是时候。”

林诗诗打断他，“苏言对我还有用。”

“小姐的意思是……”

“两年后，韩立会死在他手里。”

林诗诗道，“到那时，才是动手的时机。”

两名灰袍人对视一眼，不再说话。

“去吧。”

林诗诗挥手，“继续监视天书阁的动向。”

“是。”

两名灰袍人退下。

林诗诗独自站在山峰上，目光深邃。

“苏言……”

她喃喃道，“希望你不要让我失望。”

山风吹过，吹起她的衣袂。

一场更大的风暴，正在酝酿。

（本章完）
